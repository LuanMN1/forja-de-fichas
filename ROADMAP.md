# Roadmap — Funcionalidades implementadas

Este documento registra as entregas presentes na versão atual do protótipo.

## Etapa 1 — Estrutura e interface

- [x] Estrutura da aplicação em HTML, CSS, JavaScript e React.
- [x] Navegação entre início, campanhas, área do mestre, área dos jogadores e fichas.
- [x] Interface responsiva com tema claro e escuro.
- [x] Página inicial com apresentação dos recursos e modelos disponíveis.

## Etapa 2 — Rolagem de dados

- [x] Rolador de dados com formatos d4, d6, d8, d10, d12, d20 e d100.
- [x] Quantidade de dados, modificadores e vantagem/desvantagem em d20 no rolador completo.
- [x] Histórico local de resultados.
- [x] Rolagem animada de d20 na página inicial com histórico dos resultados anteriores.

## Etapa 3 — Modelos e edição de fichas

- [x] Modelos iniciais para D&D 5e, Ordem Paranormal, Sobrevivendo ao Horror e Tormenta20.
- [x] Criação de ficha em branco.
- [x] Editor de seções e campos com reordenação, adição e remoção.
- [x] Campos de texto, número, seleção, marcação, atributos, recursos, perícias, tabelas e cálculos.
- [x] Cálculos e fórmulas em campos configuráveis.
- [x] Salvamento automático local de fichas.
- [x] Duplicação, exclusão, importação e backup em JSON.

## Etapa 4 — Campanhas

- [x] Formulário de criação com informações gerais e organização das sessões.
- [x] Seleção de sistemas, incluindo opção de sistema próprio.
- [x] Frequência flexível conforme disponibilidade dos participantes.
- [x] Exibição de campanhas criadas localmente junto às campanhas demonstrativas.
- [x] Identificação da função de mestre ou jogador na campanha.
- [x] Filtragem de campanhas por função.
- [x] Visualizações normal e compacta, com cartões padronizados.
- [x] Paginação de campanhas com até quatro números visíveis e navegação por grupos.

## Etapa 5 — Painel do mestre

- [x] Listagem de campanhas de mestre com paginação.
- [x] Painel com navegação lateral por campanha.
- [x] Visão geral, gerenciamento de sessões e participantes.
- [x] Cadastro e edição locais de NPCs e locais.
- [x] Controle de iniciativa e turnos de combate.
- [x] Organização de roteiro, anotações e configurações da campanha.

## Etapa 6 — Painel do jogador

- [x] Listagem de campanhas de jogador com paginação.
- [x] Painel individual com menu lateral.
- [x] Ficha de personagem em três colunas.
- [x] Edição de atributos, recursos, perícias e ataques.
- [x] Inclusão de retrato, habilidades, inventário e descrição.
- [x] Rolagens de atributos, perícias e dano com histórico.
- [x] Consulta de sessões e grupo, diário individual e rolador de dados.

## Etapa 7 — Persistência e demonstração

- [x] Armazenamento local para fichas, campanhas criadas e informações editáveis dos painéis.
- [x] Campanhas e personagens fictícios para demonstração dos recursos e layouts.
